# Новая Жизнь APK v7

Исправленная версия интерфейса.

## Изменения

- Убраны тёмные подменю действий.
- Нажатие на категорию сразу показывает выбор действий на главном экране.
- Главное меню и новая игра выровнены аккуратнее.
- Кнопки и карточки стали скруглёнными.
- Добавлена фоновая музыка `assets/bg_music.wav`.
- В настройках можно включать/выключать музыку.
- Интерфейс стал компактнее и не должен улетать наверх огромным пустым блоком.

## Сборка

GitHub Actions -> Build Android APK -> Run workflow.
