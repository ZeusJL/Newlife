# Новая Жизнь APK v6

Версия с главным меню и улучшенным интерфейсом.

## Новое

- Главное меню:
  - Продолжить игру
  - Новая игра
  - Ваши игры
  - Настройки
  - Выйти из игры
- Красивый игровой главный экран
- Карточка персонажа
- Прогресс-бары статов
- Плитки действий
- Кладбище прожитых жизней
- Настройки звука, вибрации, синхронизации и Google Play Games как заготовка

## Сборка

GitHub Actions -> Build Android APK -> Run workflow.
