# Новая Жизнь APK v8 FULL

Полная тестовая версия симулятора жизни для Android на Kivy.

## Есть в проекте

- Главное меню с фоном и иллюстрацией
- Продолжить игру / Новая игра / Ваши игры / Настройки / Выйти
- Игровой экран с карточкой персонажа
- Аватары, фоновые картинки, иконки категорий
- Фоновая музыка
- Система возраста, дней, XP и уровней
- Статы: здоровье, счастье, энергия, внешность, ум, харизма, дисциплина, удача, известность
- Учёба, работа, отношения, имущество, бизнес, активы, здоровье
- События и случайные жизненные ситуации
- Кладбище прожитых жизней
- Достижения
- Цель: таблетка бессмертия
- GitHub Actions для сборки APK

## Сборка

Actions -> Build Android APK -> Run workflow -> скачать Artifact NewLife-debug-apk.
